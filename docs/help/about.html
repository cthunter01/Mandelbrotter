About Mandelbrotter

Mandelbrotter is an interactive explorer for the Mandelbrot set and its relatives, written in C++. Help > About Mandelbrotter shows the version you are running.

Built with

wxWidgetsThe user interface toolkit (wxWindows Library Licence).
nlohmann/jsonReading and writing bookmarks and view files (MIT Licence).
stb_image_writeWriting PNG files (MIT Licence / public domain).
GoogleTestThe test suite, not part of the program (BSD 3-Clause Licence).

Further reading

The rendering methods used above a zoom of 1e8 (perturbation with rebasing and bilinear approximation) come from the fractal community's work on deep zooming; the README that comes with the source describes the implementation for programmers.
