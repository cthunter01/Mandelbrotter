View files

File > Export view writes the current picture's settings to a JSON file (the suggested name is view.json); File > Import view reads one back. A view file is what a single bookmark holds, in its own file: handy for sending a place to someone, for keeping a collection outside the bookmark list, or for the command line, where --view FILE.json opens or renders it.

The format

{
  "version": 2,
  "settings": {
    "fractal":    {"family": "mandelbrot", "exponent": 2,
                   "julia": false, "seed": {"re": 0.0, "im": 0.0}},
    "view":       {"center": {"re": "-0.7436", "im": "0.1318"}, "zoom": 5000.0},
    "iterations": {"max": 256, "auto": true},
    "coloring":   {"palette": "electric", "density": 64.0, "offset": 0.0}
  }
}
  • family is mandelbrot, burning-ship or tricorn; exponent 2 to 8.
  • center holds the two coordinates as decimal strings with as many digits as the zoom needs, so a deep view reloads bit for bit; a plain number is accepted too, and version 1 files, which stored numbers, still load.
  • zoom runs from 0.1 to 1e300, max from 1 to 1 000 000, density from 1 to 4096; values outside these ranges are clamped when the file is read.
  • Unknown keys are ignored, so files written by a newer Mandelbrotter usually still load; a version above 2 is refused with a message. A file that holds only the settings object also loads. An unknown palette name falls back to classic.

The bookmark file (Bookmarks) is {"version": 2, "bookmarks": [{"name": "...", "settings": {...}}, ...]} with the same settings object.
