Troubleshooting

Rendering is slow

Deep views and high iteration limits cost time; the first pass appears quickly and the picture sharpens over the following passes, and you can navigate while it does. A smaller window renders faster, and with Auto off a lower Maximum in the Iterations section helps when the black interior dominates. If you built Mandelbrotter yourself, make sure it is a release build: a debug build is several times slower.

Nothing happens for a moment after zooming in deep

Above a zoom of 1e8 the reference orbit is computed before the first pass can appear; see Deep zoom. The pause grows with the iteration limit.

"The clipboard is busy"

Another program holds the clipboard. Wait a moment and copy again.

"Could not read ... bookmarks.json"

The bookmark file is damaged or unreadable. Mandelbrotter starts with an empty list and will overwrite the file the next time you add or delete a bookmark, so move or repair the file first if it holds anything you want to keep; see Bookmarks.

Ctrl+C in a seed field copies the picture

Ctrl+C is the shortcut of File > Copy image and wins over the text field. To copy the text of a seed field, select it and use the field's right-click menu.

A Try it link did nothing

The main window is busy with a dialog (a file chooser or the progress of a save); finish or close it and click the link again. If a message appears instead, the link is malformed: please report the page.

No window opens

On a machine without a display use the command line: --render writes a PNG without opening a window.

The help window is behind the main window

Choose Help > Contents again, or use the taskbar; the window is not modal, so both stay usable. Arrange the two side by side to use the Try it links.
